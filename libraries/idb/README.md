# @nostrwatch/idb

> **DEPRECATED** — This package was never implemented. Use the browser's native IndexedDB API or the `@nostrwatch/route66` cache adapter layer instead.

## Overview

`@nostrwatch/idb` was a planned IndexedDB wrapper for nostr-watch. The directory contains no source code — only a `node_modules` folder. The package was never developed beyond the initial directory scaffold.

## Installation

This package is deprecated and contains no code. Do not add `@nostrwatch/idb` as a dependency.

## Quick Start

This package is deprecated. No code exists to use. For browser-side persistence, use the browser's native IndexedDB API or a cache adapter via `@nostrwatch/route66`.
