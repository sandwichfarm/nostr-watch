## Overview (3-5 sentences): Monitors Nostr relay health through automated check cycles. Runs configurable check suites (DNS, info, SSL, connectivity, geo) against relay lists. Publishes results as NIP-66 events to the Nostr network. Supports clearnet and multinet (Tor, I2P) relay monitoring.

## Prerequisites: Deno >=1.40. Environment variables:

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `RELAYMON_NSEC` | Yes | Private key for signing NIP-66 events and announcements | `nsec1...` |

SQLite database created automatically at the path specified in config.yaml.

## Installation: Deno app -- no npm install.
```sh
# Ensure Deno is installed (https://deno.land)
cd apps/relaymon
```

## Quick Start:
```sh
# Configure
cp config.sample.yaml config.yaml
# Edit config.yaml -- set monitor.slug, publisher.relays, and your nsec

# Start monitoring
RELAYMON_NSEC=nsec1... deno task start
```

Additional deno tasks: `deno task interactive` (CLI), `deno task status` (report), `deno task dbcheck` (integrity), `deno task compile:linux-x64` (binary).

## Docker: Document both Docker variants:

## Configuration: Extensive YAML config via `config.yaml`. Document key sections:
- `monitor.slug`: Unique monitor identifier

- `relaymon.networks`: Which network types to monitor (clearnet, tor, i2p)
- `relaymon.retryBackoff`: Retry strategy for failed checks
- `relaymon.seed.sources`: Where to discover relays to monitor
- `relaymon.checks`: Which check types to run and their configuration
