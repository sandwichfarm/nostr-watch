**Step 1: Create `.github/workflows/docs-lint.yml`**

Two jobs in a single workflow: `markdownlint` and `linkcheck`. The workflow triggers on:
- `pull_request` with paths filter `['**/*.md']`
- `push` to `main` branch with paths filter `['**/*.md']`

**Job 1: markdownlint**

```yaml
markdownlint:
  name: Markdown Lint
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4

    - name: Lint Markdown
      uses: DavidAnson/markdownlint-cli2-action@v22
      with:
        globs: |
          libraries/*/README.md
          apps/*/README.md
          internal/*/README.md
      continue-on-error: ${{ github.event_name != 'pull_request' }}
```

Key decisions (from CONTEXT.md):
- `continue-on-error` is `true` when NOT a pull_request (i.e., push to main) — this makes it warn-only for pushes, blocking for PRs
- Globs match the same pattern as `.markdownlint-cli2.jsonc` (plan 01-01) — scoped to package READMEs only
- Uses `DavidAnson/markdownlint-cli2-action@v22` (confirmed current in RESEARCH.md)
- No pnpm setup needed — the action bundles markdownlint-cli2 and reads `.markdownlint-cli2.jsonc` from repo root automatically

**Job 2: linkcheck**

```yaml
linkcheck:
  name: Link Check
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4

    - name: Cache lychee
      uses: actions/cache@v4
      with:
        path: .lychee.cache
        key: lychee-${{ hashFiles('**/*.md') }}
        restore-keys: lychee-

    - name: Check links
      uses: lycheeverse/lychee-action@v2
      with:
        args: >-
          --cache
          --max-cache-age 1d
          --github-token ${{ secrets.GITHUB_TOKEN }}
          'libraries/*/README.md'
          'apps/*/README.md'
          'internal/*/README.md'
          'docs/**/*.md'
        format: markdown
        output: ./lychee/results.md
        fail: ${{ github.event_name == 'pull_request' }}
        token: ${{ secrets.GITHUB_TOKEN }}
```

Key decisions:
- `fail` is `true` only for pull_requests — push to main is warn-only
- `--cache` + `--max-cache-age 1d` mitigates rate-limiting from external services
- `--github-token` passed for GitHub URL checks to avoid rate limits
- Link check scope includes both package READMEs AND `docs/**/*.md` (CONTEXT.md: checks internal and external links)
- `actions/cache@v4` persists lychee's cache between runs

**Step 2: Create `.lycheeignore`**

Exclusion list for known-flaky domains (from CONTEXT.md and RESEARCH.md):

```
# Relay URLs — may be offline, used in code examples
^wss://
# Badge services — rate-limit frequently
^https://img\.shields\.io
^https://badge\.fury\.io
# npm — sometimes flaky in CI
^https://www\.npmjs\.com/package/
```

Each pattern is a regex matching the start of the URL. lychee reads this file automatically from the repo root.
