Important notes:
- Use full literal class strings (`text-gray-400`, `animate-liveness-pulse`, `text-green-400`, `text-orange-400`, `text-red-400`) so Tailwind's content scanner detects them. Never construct class names dynamically.
- The `liveness-pending` and `liveness-fresh` classes are CSS hooks for the color transition -- defined in step 3.

**Step 3: Add global CSS for color transition in +page.svelte**

In `apps/gui/src/routes/monitors/+page.svelte`, add a `<style>` block at the end of the file (after the closing `</main>` tag). Use `:global()` because the formatter HTML is injected via `{@html}` and Svelte's scoped CSS does not apply to dynamically injected HTML:

```svelte
<style>
  :global(.liveness-pending) {
    transition: color 500ms ease, opacity 500ms ease;
  }
  :global(.liveness-fresh) {
    transition: color 500ms ease;
    animation: none;
  }
</style>
```

The `transition: color 500ms ease` on both classes ensures that when Svelte re-renders a row and the class changes from `liveness-pending text-gray-400` to `liveness-fresh text-green-400`, the color smoothly fades over 500ms. The `animation: none` on `.liveness-fresh` explicitly stops the pulse when transitioning to fresh state.
