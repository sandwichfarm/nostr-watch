# @nostrwatch/sanitize

> **DEPRECATED** — This package has been replaced by [`@nostrwatch/nostrings`](../nostrings/README.md) for relay URL sanitization.

## Overview

`@nostrwatch/sanitize` was a relay URL sanitization package for nostr-watch. It has been superseded by `@nostrwatch/nostrings`, which provides relay URL normalization and validation with a broader feature set. The `libraries/sanitize` directory contains only a `node_modules` folder — no source code was retained.

## Installation

This package is deprecated. Use `@nostrwatch/nostrings` instead:

```sh
pnpm add @nostrwatch/nostrings
```
