Relay Chronicle - Browser Example

This example demonstrates using the relay-chronicle library directly in the browser.

Using with CDN

To use the library in your browser application, import it from a CDN:

<script type="module">
  import {
    composeState,
    liveness,
    whenInit,
    generateUptimeSeries
  } from 'https://cdn.jsdelivr.net/npm/@nostrwatch/relay-chronicle/dist/browser.js';

  // Your code here...
</script>

Using with npm + Bundler (Vite, Webpack, etc.)

npm install @nostrwatch/relay-chronicle

// In your code
import { composeState, liveness } from '@nostrwatch/relay-chronicle';
