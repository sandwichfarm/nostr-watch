nostr.watch: Nostr relay monitor

Free, open-source monitoring for Nostr relays. Monitors in several regions check relays every hour and publish the results as NIP-66 events. The relay table loads in your browser; enable JavaScript to use it.

Data for developers and agents

  • REST API v2 documentation and sandbox
  • CVM: MCP tools over Nostr
  • NIP-66 specification
  • llms.txt summary for agents
  • Markdown version of this page

Pricing

The website and the raw NIP-66 events are free. The REST API and CVM tools charge small per-request amounts in sats.
