## Overview (2-4 sentences): A collection of Docker Compose configurations for deploying nostr-watch services. Each stack directory contains a self-contained `docker-compose.yml` with all necessary service definitions. Stacks range from simple clearnet monitoring to multi-network setups with Tor and I2P routing via Gluetun VPN.

## Prerequisites: Docker Engine >=24, Docker Compose v2 (`docker compose` subcommand, not legacy `docker-compose`).

## Installation: No package manager installation needed. Clone the monorepo and choose a stack directory.

```sh
cd apps/docker-stacks
ls  # View available stacks
```

## Quick Start:
```sh
# Choose a stack (e.g., relaymon-clearnet)
cd apps/docker-stacks/relaymon-clearnet

# Configure
cp .env.example .env
# Edit .env with your keys and settings
cp config.yaml.example config.yaml
# Edit config.yaml with monitor configuration

# Start
docker compose up -d

# View logs
docker compose logs -f
```

## Available Stacks: Table listing all 5 stacks:

| Stack | Services | Description |
|-------|----------|-------------|
| `relaymon-clearnet/` | RelayMon | Standard clearnet relay monitoring |
| `relaymon-vpn/` | RelayMon, Gluetun | Monitoring behind VPN |
| `relaymon-multinet/` | RelayMon, Tor, I2P | Multi-network monitoring (clearnet + Tor + I2P) |
| `trawler-relaymon-clearnet/` | Trawler, RelayMon | Crawler + monitor on clearnet |
| `trawler-relaymon-multinet/` | Trawler, RelayMon, Tor, I2P | Crawler + monitor multi-network |

Each stack directory has its own README with detailed configuration instructions.

## Configuration: Per-stack configuration via `.env` and `config.yaml` files. Each stack directory contains example config files. Common config patterns:
- `.env` -- Docker environment variables (nsec keys, ports, network settings)
